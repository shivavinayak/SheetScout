# SheetScout

🔍 CSV & XLSX Keyword Search Tool
A lightweight command-line tool to search for any string or keyword across multiple .csv and .xlsx files in a directory — just like a Find feature, but for your entire file system.

✨ Features

🔎 Search any keyword or string across all CSV and XLSX files recursively, 
📄 Displays the full row of every match with all column values,
📌 Highlights the matched column with a ◄ marker,
⌨️ Press Enter with no input to exit,

📋 Requirements

Python 3.7 or higher
openpyxl library (for reading .xlsx files)

⚙️ Installation
1. Install Dependency
pip install openpyxl

2. Clone the Repository
git clone https://github.com/shivavinayak/SheetScout.git
   
4. Make the Script Executable
chmod +x SheetScout.py

🚀 Usage
Run the script
./SheetScout.py
